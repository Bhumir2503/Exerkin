# Exerkin — 🏋️‍♂️ Train. Track. Triumph.

Exerkin is a mobile fitness app built with React Native and Expo that helps users plan, log, and analyze their workouts. It supports strength training, cardio tracking, reusable routines (“Blueprints”), timers, analytics, and more — all within a clean, intuitive interface.

---

## 🌟 Features

### 🏋️‍♂️ Workout Tracking
- Log sets, reps, weight, and RPE  
- Track cardio workouts (time, distance, pace)  
- Add workout notes and images  
- Built-in **workout timer** and **rest timer**  
- Auto-save during active workout sessions  

### 📘 Blueprint System
- Create reusable workout templates for fast session setup  
- Customize exercise order, sets, rep ranges, and notes  
- Start new workouts instantly based on saved Blueprints  

### 🔐 Authentication & Onboarding
- Sign In with **Google** or **Email/Password**  
- Smooth onboarding flow captures:
  - Username  
  - Body measurements  
  - Unit system (Imperial / Metric)  
  - Theme preference  

### 🎨 Customization
- Light and dark themes  
- Choose between metric and imperial units  
- Create custom exercises  
- Reorder workouts and exercises using gesture-based UI  

### 📊 Analytics & Progress Tracking
- Total workouts completed  
- Current streak  
- Total volume lifted  
- Average workout duration  
- Weekly activity heatmap  
- Personal records and progression insights  

---

## 🛠 Tech Stack

- **Frontend:** React Native (Expo)  
- **State Management:** React Context API  
- **Backend:** Firebase Firestore  
- **Auth:** Firebase Authentication (Email, Google, Apple)  
- **Storage:** Firebase Storage (for workout images)  
- **Navigation:** React Navigation (Stacks + Tabs)  
- **UI & Utilities:**  
  - react-native-reanimated  
  - react-native-gesture-handler  
  - react-native-chart-kit  

---

## 🧭 How It Works

1. Sign in and complete onboarding  
2. Create a workout blueprint or begin a session from scratch  
3. Log strength sets (reps/weight) or cardio metrics (time/distance)  
4. Add notes, track rest, upload images, and monitor progress during the workout  
5. Save the session — data syncs automatically via Firebase  
6. View statistics and personal progression over time
